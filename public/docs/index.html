Introduction

واجهة برمجة تطبيقات متجر تطبيقات الويب التقدمية (PWA Store) - النسخة v1. توفر واجهات RESTful متكاملة للمصادقة وتصفح التطبيقات والتصنيفات وتثبيت التطبيقات وإدارتها والمراجعات ولوحة تحكم المطورين وبوابة الإشراف والمراجعة.

Base URL: https://pwa-store-api.vercel.app

مرحباً بك في التوثيق الرسمي لواجهة برمجة تطبيقات PWA Store. جميع الاستجابات تتبع نسقاً موحداً:

{
  "success": true,
  "message": "نص الرسالة التوضيحية",
  "data": { ... },
  "errors": null
}

جميع مسارات الكتابة والمسارات الحساسة محمية بـ Rate Limiting مناسب (throttle).

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_BEARER_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

قم بإرسال الرمز في ترويسة الطلب: Authorization: Bearer <TOKEN>. يمكن الحصول على الرمز عبر تسجيل الدخول /api/v1/auth/login أو إنشاء حساب /api/v1/auth/register.

المصادقة (Authentication)

نقاط نهاية إدارة المصادقة، تسجيل المستخدمين والمطورين، تسجيل الدخول، واسترجاع بيانات الملف الشخصي ورموز الوصول.

Register a new user with user or developer role.

Example request:
curl --request POST \
    "https://pwa-store-api.vercel.app/api/v1/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"first_name\": \"b\",
    \"last_name\": \"n\",
    \"username\": \"g\",
    \"email\": \"rowan.gulgowski@example.com\",
    \"password\": \"BNvYgxwmi\\/#iw\\/kX\",
    \"phone\": \"w\",
    \"role\": \"developer\"
}"

const url = new URL(
    "https://pwa-store-api.vercel.app/api/v1/auth/register"
);

const headers = {
