# Introduction

واجهة برمجة تطبيقات متجر تطبيقات الويب التقدمية (PWA Store) - النسخة v1. توفر واجهات RESTful متكاملة للمصادقة وتصفح التطبيقات والتصنيفات وتثبيت التطبيقات وإدارتها والمراجعات ولوحة تحكم المطورين وبوابة الإشراف والمراجعة.

<aside>
    <strong>Base URL</strong>: <code>http://localhost:8000</code>
</aside>

مرحباً بك في التوثيق الرسمي لواجهة برمجة تطبيقات **PWA Store**.
جميع الاستجابات تتبع نسقاً موحداً:
```json
{
  "success": true,
  "message": "نص الرسالة التوضيحية",
  "data": { ... },
  "errors": null
}
```
جميع مسارات الكتابة والمسارات الحساسة محمية بـ Rate Limiting مناسب (throttle).
